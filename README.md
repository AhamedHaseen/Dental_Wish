# 🦷 Dental Graduation Tribute — Dr. Sidheek Fathima Hima

A luxury, interactive, emotional, and fully responsive celebration website created as a surprise gift for **Dr. Sidheek Fathima Hima**, celebrating the monumental achievement of completing her final year Bachelor of Dental Surgery (BDS) and stepping out of the prestigious **Faculty of Dental Sciences, University of Peradeniya, Sri Lanka**.

Presented with love, pride, and blessings by her sister, brother-in-law, and family.

---

## ✨ Features

- **🎓 Fullscreen Emotional Hero Section**:
  - Main greeting celebrating Dr. Sidheek Fathima Hima.
  - Classical laurel wreath and university honors badges.
  - "Open Your Surprise ❤️" button with smooth scroll transitions.

- **💌 Interactive 3D Parchment Letter**:
  - Animated CSS wax-sealed envelope with authentic folding flaps.
  - Slides open with a personalized letter from her loving sister, brother-in-law, and family.
  - "Read Full Letter" fullscreen modal reader with classical parchment styling.

- **🦷 Floating Dental Scroll Companion**:
  - Animated dentist mascot tooth wearing a doctor mortarboard that glides along a glowing vertical track as you scroll down the page.
  - Tilts with scroll velocity, tracks progress percentage, and triggers surprise confetti when tapped.

- **🎼 Celebratory Background Melody**:
  - Scroll-triggered audio system powered by the Web Audio API (synthesized harp & acoustic piano chords) with automatic fallback for a custom `music.mp3`.
  - Non-intrusive floating toggle control with live sound wave animation.

- **📸 Interactive Memories Photo Gallery & Lightbox**:
  - Hover zoom cards with customizable SVG fallback placeholders for clinical moments, portraits, and university memories.
  - Fullscreen lightbox modal with touch swipe gestures for mobile phones and keyboard navigation (<kbd>←</kbd> / <kbd>→</kbd> / <kbd>Esc</kbd>).

- **🌟 Dental-Themed Showcase**:
  - Centerpiece golden tooth with orbiting dental tools (mirror, probe, sparkling enamel).
  - Inspiring dental quotes honoring the art and science of creating confident smiles.

- **🎉 Interactive Celebration Station**:
  - Interactive triggers: Golden Confetti, Floating Hearts, Pastel Balloons, and a Grand Finale celebration blast.

- **📱 100% Mobile & Touch Optimized**:
  - Tested across iPhone SE, iPhone Pro/Max, Samsung Galaxy, Android devices, and iPads.
  - Safe-area inset handling for iPhone display notches.
  - Zero horizontal overflow and touch-friendly 44px+ tap targets.

---

## 🛠️ Built With

- **HTML5** — Semantic, accessible layout.
- **CSS3** — Pure vanilla CSS with custom variables, 3D envelope geometry, glassmorphism, and responsive media queries.
- **Vanilla JavaScript** — Confetti physics canvas engine, floating particle systems, Web Audio API synthesis, scroll companion tracking, and touch swipe gestures.

*(No external frameworks, libraries, React, Bootstrap, or Tailwind used.)*

---

## 🚀 Getting Started

Simply clone or download this repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/AhamedHaseen/Dental_Wish.git
cd Dental_Wish
```

Double click `index.html` or open with Live Server in VS Code.
